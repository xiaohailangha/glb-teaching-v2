管理端需求补充 V3：每日用户时长与腾讯云官方账单
日期：2026-10-31；状态：需求分析，未实施埋点、管理页面或账单接入。
本补充调整 V1 的交付优先级；首批先交付管理员入口、时长采集、用户日报、腾讯云官方账单展示，课程编辑发布闭环随后实施。

一、负责人要回答的问题
1. 每个用户今天、昨天及任意日期用了多久，实际学习多久，学了哪些课？
2. 哪些用户连续使用、停止使用、异常长时间挂机？
3. 腾讯云语音合成、识别、评测等产品本月账单费用多少，费用明细是什么？
4. 按腾讯返回的产品、子产品、计费项查看费用构成。
5. 账单更新到什么时候，当前月份是否已最终出账？

二、每日时长口径
三项分别显示，不合并为一个“在线时长”：
A. 前台使用时长：APP 处于前台且页面可见的时间，包含浏览、课堂和前台等待；网页按 document visibility 与应用生命周期判断。不能宣称等同真人持续注视。
B. 有效学习时长：前台课堂中有教学播放、跟读录音或近期明确学习交互的时间。课程播放不要求用户持续点屏；人物空闲动画、自动心跳不算活动证据。
C. 空闲/其他时长：前台使用减去有效学习，详情再区分浏览、暂停、等待、空闲；网络等待不作为有效学习。
建议默认：最近交互后最多保留 60 秒阅读/思考时间，示范音频按真实播放区间，录音按真实捕获区间计入；显式暂停立即停止学习计时。规则可配置且记录版本。
录音已打开但持续无回应不能无限计入；单次录音有时限，连续无有效回应后学习计时转空闲，重新交互后恢复。自动循环播放也需此保护。
后台、锁屏停止前台及有效学习计时；将来支持后台听力时，单列后台收听，不偷偷改变原指标。

三、采集与计算规则
1. 建议每 15 秒提交一次短区间活动记录；进入/退出、前后台切换、暂停、账号切换时立即尝试提交，并持久化未确认队列。
2. 用单调时钟计算经过时间；服务器校验区间长度、序号、设备时间偏移与会话归属。休眠或计时器冻结后的大间隔不得补成学习时长。
3. 不依靠“退出 APP”事件结算；异常关闭最多丢失一个未持久化采样周期，展示采集完整性，不能凭缺失心跳推算离线学习。
4. 会话、设备、分段序号、事件唯一 ID 去重；同一用户多标签页/多设备的重叠时间取并集。用户时间线先合并状态，使有效学习时长不超过前台时长。
5. 同时学不同课程时，每课时长可各有重叠，用户总时长仍取并集，并说明每课相加未必等于总时长。
6. 按北京时间自然日切分，跨零点拆到两天；存储 UTC 区间与时钟可信度。时钟大幅异常记录待核验，不按手机错误日期入日报。
7. 离线先本地记录，联网后按原发生日补报；保留接收时间和离线来源，迟到记录触发历史日重算。离线客户端数据不是防作弊级证据。
8. 用户身份由服务端已验证会话决定，不能相信前端传 userId。退出或切换账号隔离队列；旧账号队列待原账号重新认证后提交，不能挂到新用户。
9. 游客单列，不凭设备/IP 猜测用户身份；采集前的历史时长显示“未采集”，不能从课程断点推算。
10. 在线人数另按近期心跳定义，仅是估计，不用于累计学习时长。

四、管理页面与导出
用户日报：日期、昵称、账号 ID、脱敏手机号、前台时长、有效学习时长、使用会话数、课程数、练习次数、首次/末次活动、数据同步状态。
支持单日/日期范围、用户搜索、时长排序、测试账号排除、仅活跃/所有用户切换；注册前或采集前不填零，采集覆盖不完整明确标记。
用户详情：近 7/30 天时长趋势、每日明细、当日会话时间线、课程和阶段、暂停/离线/异常记录。
运营概览：每日活跃用户、总前台/有效学习时长、人均时长、中位数、留存趋势。人均分母说明：当天有有效学习的用户数。
导出复用页面口径、日期范围与权限，包含时区、规则版本、生成时间和数据状态；手机号默认脱敏。

五、费用范围修订（用户明确要求）
直接接入腾讯云官方账单，不开发本地实时费用计算、价目表、调用成本流水、用户成本分摊、课程成本归因、套餐摊销或自建对账系统。
用户每日时长独立采集；费用数据与用户时长不挂钩。

六、已核实存在的官方接口
请求域名：billing.tencentcloudapi.com；API 版本：2018-07-09。
1. DescribeBillSummaryByProduct：按产品获取月度费用分布，适合费用首页。BeginTime/EndTime 同月，返回整月数据，不把此接口当任意日期区间查询。
2. DescribeBillDetail：获取账单明细，适合查看产品、子产品、组件计费项、用量单位和费用等官方返回字段。具体字段与服务粒度以实际响应为准。支持分页，单页上限 300，文档注明最多近 18 个月。
3. DescribeBillResourceSummary：资源汇总，首期按需要接入；首页和明细可先只用前两项。
腾讯已提供账单 API，不需要从零实现计价引擎。这里的“各 API 费用”按腾讯产品/子产品/计费项展示，不承诺逐 HTTP 请求、逐 WebSocket 或逐 APP 用户的金额。

七、最小费用页面
- 月份选择；本月已出账费用；语音合成、语音识别、口语评测等产品费用列表。
- 产品明细：直接展示腾讯给出的计费项、用量/单位、费用、抵扣等字段；用量缺失则留空，不反推。
- 显示最后同步时间、同步是否成功、本月账单尚未最终确定的状态。
- 每日自动同步一次，另提供手动刷新（带限频/缓存）；失败保留上次成功数据并标注过期。
- 服务器后台持有只读账单权限，前端不接触密钥；首期无需购买、付款、充值或退订权限。
- 同一个腾讯账号其他项目的费用也可能返回：页面注明账号范围，只有腾讯支持且可核实的产品/资源/项目条件才用于筛选。不自行强行分摊。
- 未接入/无权限/无账单/零费用明确区分。套餐购买和消耗按腾讯账单原样解释，不自行造每日使用成本。

八、数据更新周期
依据腾讯中国站账单 FAQ：L0–L2 汇总账单 T+1 出具；L3 明细在扣费后半小时内出账。是“扣费后”，不是“API 调用后”。各服务日结/月结会影响何时可见。
上月账单每月 1 日 19 点最终出账；此前当月及未最终出账金额仅供参考。界面不标实时费用，不用自算数补齐未出账费用。

九、实施与验收
首期：管理员入口、每日用户时长采集/日报、腾讯产品费用汇总与明细。
费用验收：同账号同月份与腾讯控制台账单口径相符；分页不漏；刷新不重复；失败不清空旧数据；未最终出账状态明显；没有本地估价金额。
本次仅完成公开 API 文档核实及需求修订，尚未调用本账号费用 API；实际权限、产品返回颗粒度待开发联调核实。
