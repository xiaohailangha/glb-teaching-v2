Web r8 学习体验改进（2026-10-30）

用户要求：句子逐词试听；出现过的词跨课标蓝；结课给出词汇增量；无需每次点跟读；美式标准音标不使用单词切片；修复 banana 疑似尾音；右侧无滚动；文本动效克制；图片未来不需要用户逐张审核。

实现
1. LearningText 逐词点击，当前水果课全部九个词 I/want/to/eat/an/apple/a/banana/red 有独立语音。按大小写归一的接触记录标蓝，暂停/重开课程不重复增加；本机持久化供后续课程复用。当前累计是接触词形数，不等同于掌握或严格词元量；未来更大词库需要词形归一映射。
2. VocabularyLedger 只接收当前可见教学文本及实际开始播放的词句，不预先扫描全课程计数；隐藏答案不因为藏在 JSON 里而计数。首页已经出现 apple 会先入账，第一课增量因此可能比全课总词数少一个。课程总结显示本课新增和累计，首次启用功能之前的完整历史无法追溯，不伪造历史记录。
3. 自动跟读由用户主动开启麦克风，当前练习目标内本地采集 PCM，约 0.8 秒停顿后上传一句到现有腾讯 SOE。不是逐音素流式即时判错；网络往返仍需时间。统一按手机外放设计，不提供耳机模式或要求耳机。示范播放后自动收音评测；示范播放中的重叠跟读暂不评分，以免把示范当成用户。外放下同时读的可靠分离仍是后续改进项。
4. 无目标、纯静音、暂停/退出/结束时不上传；离开页面会暂停并关麦。结果绑定当前目标，旧阶段结果丢弃。低分单词可回放独立词示范，结果不足时提示重说，不宣称低分一定是发错。真人麦克风、外放回声和噪声仍需实际验证。
5. 右侧改为固定学习卡片，无 Scrollable；按高度压缩间距与图片，内容极端超限才等比缩小。Flutter 文本不是 DOM，使用原生 AnimatedSwitcher 淡入/轻移，未添加无效的 GSAP 依赖。逐词点击蓝色标记，操作在当前步可见。详细音标参考放在对话框。

音标和 banana 调查
现有 NotoSansSC-ui.ttf 缺少 ə/ˈ/ː/ɪ/ʊ/ʌ/ɔ/ŋ 等 IPA 字符。独立 NotoSans IPA 字体补齐，并保留 OFL 许可；中文子集按现有源码/课程重建。
旧 banana 对齐：b ah n ae n ah，第二个 n 被拉长约 0.30 秒，整段裁切后 1.47 秒；ASR 返回 Banana奶。不能据此证明多了一个音节，但证明生成结果值得替换。
新 banana. 对齐 b ah n ae n ah，两个 n 各约 0.10/0.06 秒；完整候选 ASR 返回 Banana.。使用同一男童声线重生成，整词只去除首尾空白，不拿其片段制作音标。
美式 banana /bəˈnænə/：https://www.oxfordlearnersdictionaries.com/us/definition/english/banana
apple 音标参考：https://dictionary.cambridge.org/pronunciation/english/apple
音节边界点只帮助阅读，不是额外读音；重音符号不读出来。连读中的 a/an/to 有弱读，点词是独立词读法。
全部旧单词切片式独立音标已替换为独立 IPA 录音。来源 Ruben Schachtenhaufen 的 IPA-sound-files（CC0）及 Wikimedia Commons 的 ə/ɪ/ʊ（按各文件 CC BY-SA 许可）。来源原文件仅转换格式/采样率，不切割、不变速变调；每项附作者、原地址、许可证和 SHA-256。声线与人物不同并明确说明。中性口型，不伪造参考录音时间轴。
/əl/ 是组合，/oʊ/ 是双元音，没有新的已核对组合录音，本轮撤下旧切片试听，保留文字及整词示范，不以分离音素拼接冒充自然读法。
