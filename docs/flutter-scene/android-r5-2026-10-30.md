## 构建

使用独立 Flutter 3.47.9，未修改旧 D:\flutter。首次构建由 Gradle 补齐 Gradle 9.3.1、NDK 28.2.13676358、Build Tools 36.0.0 和依赖需要的 Android Platform 35，保留既有 SDK/NDK 版本。首次 release 用时约 791 秒。

```powershell
./tools/flutter-scene.ps1 build apk --release --target-platform android-arm64 --no-pub --build-name 0.2.0 --build-number 5
./tools/verify-scene-apk.ps1
node tools/publish-scene-apk.mjs
```

aapt 对中文绝对路径会报 Illegal byte sequence，校验工具已采用工程目录下相对路径，重新校验通过；这不是 APK 文件损坏。
