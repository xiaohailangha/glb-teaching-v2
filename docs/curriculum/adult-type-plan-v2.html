基础表达 · 12课

B01 苹果和香蕉

已上线

从辨认水果走到表达想要和想吃。

单词（含复用）
apple / banana / eat
短语
an apple
a banana
want to eat
句子
I want an apple.
I want to eat a banana.
场景任务
选自己想吃的水果，再在没有英文提示时向人物提出请求。
教学注意
a/an 按后接发音区分；I、want、to、eat 都要教，red 维持可选扩展。

前置：无，可从这里开始
验收：隐藏英文后完成任务，替换一个已学条件再表达。
